# Coffee Sales Analysis

## 🗂️ Dataset

The dataset used in this project is the [**Coffee Sales**](https://www.kaggle.com/datasets/ihelon/coffee-sales/data?select=index_2.csv) dataset, created by **Yaroslav Isaienkov** and published on Kaggle.

It contains transaction records from a coffee vending machine, including information about the date and time of each transaction, payment method, transaction amount, and coffee purchased.

The dataset is suitable for exploring **sales trends, purchasing patterns, and customer preferences**.

### Dataset Source

- **Source:** Kaggle
- **Author:** Yaroslav Isaienkov
- **File used:** `index_2.csv`
- **License:** CC0: Public Domain

### Main Features

| Column | Description |
|---|---|
| `date` | Date of the transaction |
| `datetime` | Date and time of the transaction |
| `cash_type` | Payment method used for the transaction |
| `money` | Transaction amount |
| `coffee_name` | Name of the coffee purchased |
